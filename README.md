# SonoForm downloads

Official distributions of SonoForm, the clinical documentation assistant for ultrasound:
https://getsonoform.com

- `releases/android/` - Android app (APK). Latest build is also available at https://getsonoform.com/app
- `releases/desktop/` - desktop workstation installers (Windows, macOS, Linux)

Every file is listed in `releases/CHECKSUMS.txt` with its SHA-256. This repository contains
distributions only; there is no source code here.
